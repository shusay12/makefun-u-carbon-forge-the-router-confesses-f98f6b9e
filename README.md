# The Router Confesses

A one-line excuse a home Wi-Fi router gives for dropping the connection at the climax of a movie, 200 characters or fewer. `main.py` (Python 3.13, standard library only, no network) writes it to `/output/entry.txt`.

> I saw who did it ten minutes ago and I'm not letting you find out first — some of us watch too, you know.

## Why this line

- **First-person router voice** — the appliance itself talking, petty and quietly smug, not a generic apology.
- **A turn the reader doesn't see coming** — the router isn't broken; it secretly watched ahead and is withholding the reveal out of jealousy.
- **Fresh angle** — no buffering, bandwidth or firmware-update joke; the router is a fellow viewer with a grudge.
- **Lands in one breath** — a single line that reads clean, no setup to explain.

## Running it

```sh
python3 main.py   # writes /output/entry.txt (105 chars, single line)
```
